# BCON制作アドオン マニュアル

森づくり / カット管理 / 動物ポップ（各 v1）
作：majimeru + とびうおぴょんぴょん　／　確認済み環境：Blender 5.3

---

## 共通：入れ方と場所

1. Blender の「編集 ＞ プリファレンス ＞ アドオン」を開く
2. 右上のメニューから「ディスクからインストール」で、zip のまま（解凍しない）か .py を選ぶ
3. 一覧に出たら、左のチェックを入れて有効化する

- パネルの場所は3つとも同じ：3Dビューのサイドバー（**Nキー**）＞ **Majimeru** タブ
- 3つは別々のアドオンなので、全部入れてもぶつからない
- 古い版と入れ替える時だけ、先に古い版を「削除（Remove）」してから新しい版を入れる

## 1. 森づくり（majimeru_forest_v1）

木や岩を地面の形に沿ってばらまいて、色を「手前は濃く、遠くは淡く」の3層に自動で分ける。木に風のそよぎも付けられる。

### 準備

- **ばらまく物**：木や岩のモデルを、1つのコレクションにまとめておく（例：「Trees」というコレクションに木を3種類）
- **地面**：散布先の地面オブジェクト（坂道でもOK。形に沿って置かれる）

### 手順

1. パネル「森づくり」で、**ばらまく物** のコレクションと **地面** を選ぶ
2. **数**（何本ばらまくか）と **大きさ最小／最大** を決める
3. **「森をばらまく」** を押す → 「MajimeruForest」というコレクションに結果が入る
4. 並びが気に入らなければ、**タネ** の数字を変えてもう一度（数字ごとに並びが変わる）

### 色の3層

- 距離は **カメラの位置** から測る（カメラが無い時は原点から）
- **手前の終わり (m)** より近い物 → 手前の色（濃いティール）
- **中間の終わり (m)** まで → 中間の色（鮮やかな緑）
- それより遠く → 遠くの色（淡い青紫）
- 色は3つとも後から変えられる。変えたら、ばらまき直すと反映される

### そよぎ

1. 揺らしたい物を選ぶ（森の木でも、単体の木でもOK）
2. **「選んだ物にそよぎを付ける」** を押す
3. ジオメトリノードの「そよぎ」が付く。根元は動かず、上の方だけ揺れる。再生（スペースキー）で確認

### 注意

- ばらまいた物の **マテリアルは3層の色に置き換わる**（元の色やテクスチャは外れる）。絵作りのための仕様
- 数を増やすほど重くなる。最初は100〜300くらいで試すのがおすすめ
- 置き場所はランダムなので、道の上にも出ることがある。道沿いは後から手でどけるか、タネを変えて試す

## 2. カット管理（majimeru_shots_v1）

カット（C01、C02…）ごとに「カメラ」と「フレーム範囲」を覚えさせて、切り替えと連続レンダーを楽にする。

### カットの登録

1. 先に、使いたい **カメラ** をシーンカメラにして、**フレーム範囲**（開始／終了）を決める
2. **「＋」ボタン（今の設定でカットを追加）** を押す → 今のカメラと範囲でカットが登録される
3. カットを選ぶと、下で **名前・カメラ・開始・終了・メモ** を直せる
4. いらないカットは「−」ボタンで消す

### 切り替え

- カットを選んで **「このカットに切り替え」** → カメラとフレーム範囲がそのカット用に切り替わり、開始フレームに移動する

### 全カット連続レンダー

1. パネル下の **保存先** を決める（例：`//renders/render_`）
2. **「全カットを連続レンダー」** を押す
3. ファイルは **カット名＋連番** で分かれて保存される（例：`C01_0001.png`、`C02_0005.png`）
4. 終わると、カメラとフレーム範囲は元の設定に戻る

### 注意

- レンダー中は Blender の画面が止まる（裏で1カットずつ描いているため）。長いカットが多い時は時間に余裕のある時に
- 解像度やレンダラー（EEVEE／Cycles）の設定は、「簡易レンダー設定」の方で決めた物が全カット共通で使われる

## 3. 動物ポップ（majimeru_pop_v1）

動物が木の陰などから「チラッと出て、すぐ戻る」動きを、ボタン1つで作る。

### 手順

1. 動物を **「出て見せたい場所」** に置く（これが基準になる）
2. **隠れる方向** を決める：
   - 「左から／右から／地面から／上から」のボタンで大まかに決める
   - **隠れる量 (X,Y,Z)** で細かく調整（例：Xが −2 なら、左へ2m隠れて、右へ出てくる）
3. **タイミング** を決める：
   - **出るフレーム**：姿が見え切るフレーム
   - **戻るフレーム**：隠れ位置に戻るフレーム
   - **出るのに使うフレーム数**：出てくる動きの速さ（小さいほどパッと出る）
4. **「ポップを設定」** を押す → 移動と表示／非表示のキーが自動で打たれる
5. 再生して確認。跳ねるような動き（ポップ感）が付いている

### 消し方

- **「ポップを消す」** を押すと、このアドオンが打ったキー（場所と表示／非表示）を消す

### 注意

- キーは「場所（location）」と「表示／非表示」に打たれる。**その動物に元々のアニメーションがある場合、「ポップを消す」で場所のキーが全部消える** ので、元のアニメがある物には使わないか、先に控えを保存しておく
- 隠れ位置は「木の陰」を想定した単純な移動。木に隠れ切らない時は、隠れる量を大きくするか、動物の置き場所を調整する

## 困ったとき

- **パネルが出てこない** → 3Dビューで Nキー を押してサイドバーを出し、「Majimeru」タブを選ぶ
- **アドオン一覧に無い** → インストール直後は検索欄に「Majimeru」と入れると出やすい
- **ボタンが押せない／エラー** → 何を選んでいるか（コレクション、地面、動物など）が足りていないことが多い。各マニュアルの「準備」を見直す
- **前の設定に戻したい** → Blender の標準機能はそのまま使える。この3つは補助の道具なので、使わない場面では無効化してもデータは壊れない（森の散布結果やカットの登録はシーンに残る）
